# Michael.dev — Web services landing page

Landing page for my freelance web development services for local businesses in Neiva, Colombia.

**Live:** https://menticio.github.io

## Features

- Pricing plans: digital menu with QR code, basic page, full site, and maintenance
- Portfolio section with real projects (AlertaMujer, agency client sites)
- Step-by-step "how I work" section
- WhatsApp contact buttons with pre-filled messages, plus a floating button
- Responsive layout for mobile, sticky header, and smooth scrolling

## Tech stack

- HTML5 and CSS3 (custom properties, Grid, Flexbox)
- No frameworks, no build step, and no backend
- Google Fonts (Sora and Inter)
- Hosted on GitHub Pages

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then go to http://localhost:8000.
